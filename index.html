Paramètres

🔄 Nouveau départ

Remet à 0 les commandes, le chiffre d'affaires, les rapports, la comptabilité et le trafic à partir d'une date. La liste des clients est gardée (noms, téléphones, quartiers) avec leurs compteurs à 0. Rien n'est supprimé : les anciennes commandes restent dans Supabase et vous pouvez tout réafficher.

📲 Application & notifications

Installez l'espace admin comme une application sur ce téléphone, et recevez une notification à chaque nouvelle commande, même téléphone verrouillé.

Livreurs : leur application est sur khedar48.com/livreur (même bouton dans leur écran).
